# Brand mark

The mark is a workspace identity tag: a concrete object for answering “which
workspace is this?” Its large punched aperture reads as a tag at favicon size,
while the stepped right edge echoes a nested filesystem path.

The design deliberately avoids the common developer-tool shortcuts: a terminal
chevron, braces, an AI sparkle, a map pin, or a bare monogram. `master.svg` is
the editable source; generated web assets live in `site/public/`.
